# Résumé direction

Decided from `/proto/resume-direction`, `/proto/resume-type`, and `/proto/resume-voices`.

- Direction: Field Notes — warm cream canvas, electric-blue accent, indexed sections, fine rules, no shaders.
- Typography: IBM Plex Sans for display and reading; IBM Plex Mono for labels, dates, and metadata.
- Recognition: Recognition Index — all five quotes remain visible in a compact, scannable list.
- Wrapping: `text-wrap: balance` for headings; `text-wrap: pretty` for standfirsts and testimonials.
- Rejected: shader treatment felt dated and obscured prototype pages.
- Rejected: Silkscreen compromised name and heading legibility.
- Rejected: Lora made the résumé feel literary rather than product-technical.
- Rejected: Feature + Chorus made one endorsement disproportionately large.
- Rejected: Editorial Stream added too much vertical length for a résumé.
